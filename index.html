Channel Stats Lab

A private tool for one YouTube channel

Channel Stats Lab is a small program that the owner of one YouTube channel runs on their own computer. It is not a public app. Nobody else signs in to it, and it only ever works with that one channel.

What it does

  • Reads the channel's own YouTube statistics and analytics, such as views, watch time and where viewers stopped watching, so the owner can see which videos work and plan better ones.
  • Uploads the channel's own finished videos to YouTube as private, so the owner can watch each one and publish it themselves.

It cannot publish, edit or delete any video, and it never posts anything public.

Channel Stats Lab uses YouTube API Services.
